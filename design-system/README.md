## Para mudar

1. Mudou na marca: atualizar `fonte/` a partir do Drive (pasta `1FkVIaQhBfkrSXu6ImNCRZrELUCWZVuaV`).
2. Editar o arquivo em `project/`.
3. Republicar só os arquivos alterados no mesmo artifact, com `root` nesta pasta. O índice `design-system.json` vai por último e só quando uma chave dele muda; ler a versão publicada antes de reenviar.
4. Espelhar em `remotion/src/marca.ts` se a mudança for de cor, fonte ou raio.
