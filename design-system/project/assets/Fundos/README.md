# Fundos

Dez fundos da versão 1.1, 1920 × 1080, sem texto nem símbolo incorporado. São aplicações propostas, não elementos obrigatórios.

Usar em entradas institucionais e peças de comunicação. Em tabelas, documentos e qualquer área de conferência, usar superfície plana: nada de textura, brilho ou movimento atrás de dado.

Sobre os fundos escuros (01, 02, 03, 06, 07, 08, 10) a assinatura vai em branco. Sobre os claros (04, 05, 09) vai em grafite, floresta ou com a estrela em degradê.
