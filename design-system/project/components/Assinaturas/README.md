As três assinaturas, cada uma com um papel. Profissio identifica a origem; a estrela identifica o produto.

| Contexto | Assinatura | Largura de partida |
| --- | --- | --- |
| Institucional, primeira identificação | Profissio Licit com o P oficial, **sem estrela** | 240 px (320 px quando houver espaço) |
| Produto apresentado sozinho | Estrela + Licit | 160 px |
| Aplicativo, avatar, favicon | Estrela isolada | 32 px (24 px em área compacta) |

- Em fundo escuro, a versão branca. O degradê é só da estrela e só em fundo claro.
- Área livre: um quarto da altura visível, em todos os lados.
- Nunca P + estrela na mesma assinatura. Nunca o P isolado como ícone da Licit.
- Sempre o SVG do grupo Logos. Não redigitar, não redesenhar, não aplicar contorno, sombra ou brilho.
- A estrela não é selo oficial, certificação nem garantia.
