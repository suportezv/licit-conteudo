Botão de ação, em quatro variantes de classe sobre `.button`: `primary`, padrão, `ghost` e `danger`.

- **Uma ação principal por tela.** O `primary` usa `licit-action-bg`: acento no tema escuro, floresta no claro.
- O rótulo é um verbo do trabalho: analisar, enviar, revisar, conferir. Nunca promessa ("Ganhar licitação").
- Altura mínima de 40 px, 44 px em toque. Ícone sempre acompanhado de texto.
- `danger` só para ação destrutiva, com confirmação.

Quem usa fornece o rótulo e, se houver, o ícone em linha (herda `currentColor`).
