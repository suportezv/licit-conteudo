Selo de estado. Classe `.badge` com as variantes `info`, `success`, `warning` e `danger`.

**Os estados não são sinônimos**, e o selo precisa dizer exatamente qual é:

- **Processado**: etapa técnica concluída.
- **Citação validada**: uma referência conferida.
- **Revisado**: ação feita pela equipe.
- **Requisito atendido**: conclusão da equipe, nunca automática.

Estado nunca depende só de cor: sempre com texto. A estrela da marca não é estado de sucesso.
